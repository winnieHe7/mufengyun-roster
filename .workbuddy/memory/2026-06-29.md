## 登录态持久化修复
- **问题**：刷新页面后登录态丢失，被弹回登录页（过一段时间也会自动退出）
- **根因**：`AuthContext.jsx` 中登录态恢复放在 `useEffect`（异步执行），React 首次渲染时 `currentUser` 为 `null`，路由守卫（ProfilePage 的 `<Navigate to="/login">`）立即跳转，来不及恢复
- **修复**：将 `readFromStorage(STORAGE_KEYS.USER, null)` 从 `useEffect` 提到 `useState` 初始化器（同步执行），确保首次渲染就有登录态
- **效果**：登录态永久驻留 localStorage，只有主动退出登录才清除
- **文件**：`src/context/AuthContext.jsx`
- 已提交推送到 GitHub main 分支 (commit 0b3fb73)
